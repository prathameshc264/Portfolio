SalesCast Pro — AI-Powered Sales Forecasting Platform

Time-Series Intelligence, Statistical Anomaly Detection & SHAP Explainability

Overview & Problem

Small businesses and retail teams lack accessible, interpretable sales forecasting and anomaly tracking tools, relying on manual data analysis and spreadsheet guesswork rather than automated machine intelligence.

Key Implementations & Features

  • An end-to-end sales intelligence web app using Python and Streamlit with auto-detection of CSV/Excel columns (revenue, profit, cost, quantity, category) using keyword-priority matching — eliminating manual column mapping.
  • Anomaly detection engine using IQR-based statistical analysis to flag unusual sales spikes or drops, with auto-generated plain-English explanations for each anomaly.
  • SHAP with an XGBoost model to provide feature-level explainability, showing which factors (day of week, seasonality, trends) drive sales predictions.
  • OCR-based bill scanning using EasyOCR to extract structured data (date, amount, items) from uploaded invoice images and auto-ingest into the SQLite database for analysis.

AI-Powered Healthcare Platform
